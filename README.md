# Retail Sales & Profitability Analysis

## Project Overview
This project focuses on analyzing retail sales data to identify business trends, understand product performance, evaluate profitability, and explore customer purchasing patterns using Python libraries.

The project demonstrates the complete Exploratory Data Analysis (EDA) workflow, from raw dataset exploration and data cleaning to feature engineering, visualization, and business insights.

## Objectives
- Analyze overall sales revenue and profitability.
- Identify top-performing and low-performing products.
- Compare sales performance across regions.
- Understand customer segment purchasing patterns.
- Examine the relationship between discounts and profit.
- Analyze monthly and quarterly sales trends.
- Evaluate profit margins across product categories.

## Installation and Execution

Clone the repository:

```bash
git clone https://github.com/YOUR-USERNAME/retail-sales-profitability-analysis.git
```

Navigate to the project directory:

```bash
cd retail-sales-profitability-analysis
```

Install the required libraries:

```bash
python -m pip install -r requirements.txt
```

Launch Jupyter Notebook:

```bash
python -m jupyter notebook
```

Open `notebooks/Retail_Sales_Analysis.ipynb` and run all cells.

## Dataset Information
The project uses a simulated retail sales dataset containing 2,630 records before cleaning, including intentionally introduced duplicate records and missing values for data-cleaning practice.

**Note:** The dataset is generated for educational purposes. It does not represent actual company transactions or customer records.
