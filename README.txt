RETAIL SALES & PROFITABILITY ANALYSIS
=====================================

A major Python Libraries / Exploratory Data Analysis project.

PROJECT CONTENTS
- dataset/retail_sales_uncleaned.csv : simulated raw retail sales data with intentional duplicates and missing values
- notebooks/Retail_Sales_Analysis.ipynb : complete Jupyter notebook
- output/ : cleaned dataset is exported here after running the notebook
- requirements.txt : required Python libraries

RUN IN VS CODE (WINDOWS)
1. Extract the ZIP file.
2. Open the Retail_Sales_Profitability_Analysis folder in VS Code.
3. Open Terminal > New Terminal.
4. Optional: create a virtual environment:
   python -m venv .venv
5. Activate:
   .venv\Scripts\Activate.ps1
6. Install:
   python -m pip install -r requirements.txt
7. Start Jupyter:
   python -m jupyter notebook
8. Open notebooks/Retail_Sales_Analysis.ipynb.
9. Select a Python kernel and click Run All.

DATASET DISCLAIMER
All records are simulated and generated for educational practice. They are not real sales transactions, customer records, or actual company results. Do not present analysis results as real business performance.
